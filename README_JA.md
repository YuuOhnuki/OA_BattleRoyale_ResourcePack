# OA BattleRoyale Resources 1.9.14

resourcepacksへZIPのまま入れて有効にしてください。旧OAリソースパックは外し、この完全版のみを使用します。包帯・応急キット・たやゆゆの専用モデルを含みます。データパック1.9.14と組み合わせて使用してください。


## キリングのお面
正面には提供画像KillingFace.pngをそのまま使用しています。正面とひも・裏面の素材をすべてアイテム用アトラスへ登録し、ブロック用アトラスとの参照混在を避けています。装着時は正面の四角いお面と、頭の左右から後頭部へ回る灰色のひもだけを描画し、それ以外の頭部分は透明です。自分のスキンの髪や後頭部が見えます。インベントリは左右45度・上方20度の斜めから、お面と側面・後部の灰色のひもが見える表示です。表示倍率は1.1倍に抑え、枠内に収めています。手持ち・地面にも、お面と立体的な灰色のひものモデルを使用します。

データパック1.9.14のまま使用できます。装備の能力・MCID・所持制限等は変更しません。このZIPは他の装備・アイテム・マップ表示の素材も含む完全版です。古いOAリソースパックは無効にして、この完全版を有効にしてください。ゲーム内でF3+Tを押すとリソースを再読み込みできます。

ファイル形式、UV位置、正面画像の一致、参照先の静的検査を実施しました。Minecraft内での装着・表示角度の実機検証は未実施です。


## たやゆゆの武器
提供されたtayayuyu.png（50×50、透過PNG）を、そのまま武器のテクスチャとして使用しています。画像はインベントリ・手持ち・地面・ロビー展示に共通で反映します。手持ち・地面・展示などの表示は元の1.75倍に拡大し、インベントリのアイコンは枠内に収まる元の倍率を維持します。能力やデータパックの変更は不要です。


## laziの防音マスク
参考写真を元に、口元を覆う黒い立体カップ、頭上・側面・後頭部の黒い布バンド、下部のマイク端子と短いケーブルを組み合わせたMinecraft用モデルを作成しています。顔全体をプレイヤーヘッドで覆う方式から、顔の上半分が見える立体マスクへ変更しています。写真そのものを貼り付ける方式ではありません。

このマスクの装着表示にはデータパック1.9.14とリソパ1.9.7の両方が必要です。既存の所持マスクは、データパックの通常インベントリ判定で新しい外観へ更新します。被り物の描画ベースはくり抜かれたカボチャですが、明示した装着コンポーネントにはカボチャの視界オーバーレイを設定していません。能力・名前・MCIDは維持します。装着位置・サイズのMinecraft内実機検証は未実施です。


たやゆゆは画像下端を握り位置の基準とし、拡大したまま手から離れないよう表示コンテキストごとに持ち位置を調整しました。モデル全体を後から拡大して表示位置まで移動する方式は廃止しています。ほちきすは赤い可動カバー、金属マガジン、後部ヒンジ、台座のアンビル、紙を追加し、手持ち等の表示倍率を従来の1.25倍にしています。ゆったりはF_KiRiSaN_1110のスキンを、頭・胴・両腕・両脚と各外側レイヤーに貼った立体人形です。手持ちの高さは従来のおよそ2倍の表示倍率、インベントリは枠内に収めています。実際の手との重なり・見た目はMinecraft内では未検証です。


小豆バーをMinecraftらしい角を落とした棒アイスと木目の棒にし、表面に小豆粒と淡い氷の粒を追加しています。写真風テクスチャは使わず、アイテム用アトラスへ登録したバニラ素材を使用します。手持ち・地面等の倍率は直前の1.75倍。ゆったり人形は直前の0.75倍に縮小し、握り位置を再計算しました。インベントリは枠内の倍率です。火球・上昇の修正には同版データパックも必要です。
